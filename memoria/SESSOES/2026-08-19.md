# Sessão 2026-08-19 — Arquitetura de Agentes IA com Múltiplos Provedores

## Resumo

Sessão dedicada a configurar e validar arquitetura completa de agentes IA combinando provedores locais e cloud.

## Etapas realizadas

### 1. Configuração do ambiente
- OpenCode 1.18.18 em uso
- Ollama instalado localmente com três modelos:
  - gemma4:12b
  - gemma4:26b
  - 4skl/gemma4-e4b-mtp:latest

### 2. Provedores configurados
- **Cloud:** OpenCode Free com opencode/mimo-v2.5-free
- **Local:** Ollama com modelos gemma4
- **Roteador:** 9Router v0.5.55

### 3. Configuração do 9Router
- Instalado em http://localhost:20128
- Configurado no opencode.json com endpoint http://127.0.0.1:20128/v1
- Autenticação ativada através do mecanismo de credenciais do OpenCode
- Combo ProjetoLab disponibilizado como 9router/ProjetoLab

### 4. Validação de ProjetoLab
- Teste 1: Prompt "Responda apenas: PROJETOLAB + 9ROUTER + OPENCODE OK"
  - Resultado: ✅ Sucesso
  - Provider utilizado: claude-haiku-4.5 (verificado no painel do 9Router)
- Teste 2: Prompt "Responda apenas OK"
  - Resultado: ✅ Sucesso

### 5. Avaliação de modelos locais
- Modelos Ollama funcionam corretamente
- Desempenho: lentos no hardware atual
- Decisão: manter Ollama para testes locais, priorizar cloud para desenvolvimento de agentes

### 6. Estratégia de combo ProjetoLab
Três opções a avaliar:
- **Fallback:** tenta cloud primeiro, cai para local se indisponível
- **Round Robin:** alterna entre cloud e local em cada requisição
- **Fusion:** combina respostas de múltiplos provedores

Ainda não foi definida qual estratégia usar.

## Aprendizados

1. Arquitetura multi-provider funciona com OpenCode + 9Router + Ollama
2. As credenciais do 9Router foram armazenadas pelo mecanismo de autenticação do OpenCode, separadamente do opencode.json.
3. Painel do 9Router oferece visibilidade de chamadas e provedores utilizados
4. Cloud é recomendado para agilidade em desenvolvimento; local ideal para testes e cenários offline
5. Combo ProjetoLab reduz complexidade ao abstrair múltiplos provedores atrás de interface única
