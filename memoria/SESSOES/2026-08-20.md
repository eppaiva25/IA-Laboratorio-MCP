## Etapas realizadas

### 1. Cofre DPAPI da chave OpenRouter

  via DPAPI, vinculada ao usuário/máquina).

- Nova chave gravada em 20/08/2026. A chave nunca existiu em texto puro em disco
  nem dentro do repositório.

### 2. Validação da nova chave

1. Leitura do cofre: `Get-Content key.sec | ConvertTo-SecureString` (com
   `PSCredential` para manipular o segredo sem exibi-lo).
2. Comprimento/formato: **73 caracteres**, prefixo **`sk-or-`** — formato válido.
   Apenas metadados foram exibidos; o conteúdo da chave jamais foi impresso.
3. `GET https://openrouter.ai/api/v1/models` → HTTP 200, catálogo de modelos retornado.
4. `GET https://openrouter.ai/api/v1/key` → HTTP 200, dados da chave confirmados.
5. Teste direto de `anthropic/claude-haiku-4.5` via `/api/v1/chat/completions`
   com `max_tokens=1000` → resposta gerada com sucesso.
6. Uso e custo retornados pela API nesta chamada:

### 3. Problemas encontrados e soluções

| Problema | Causa | Solução |
|----------|-------|---------|
| `401 Missing Authentication header` | Requisição sem o cabeçalho `Authorization` (quoting do `curl.exe` no PowerShell) | Usar `Invoke-RestMethod` com `Headers @{ Authorization = "Bearer $key" }` ou aspas simples no `curl.exe` |
| Falha de autenticação com a chave anterior | A chave anterior apresentou falha de autenticação; foi realizada rotação para uma nova chave, que foi validada com sucesso. As duas chaves têm o mesmo formato (73 caracteres, prefixo `sk-or-`) — o que mudou foi o conteúdo | Rotação registrada no cofre DPAPI com backup prévio; nova chave validada ponta a ponta |
| Erro `402` no teste do modelo | Limite de créditos associado ao `max_tokens` solicitado | Repetir o teste com `max_tokens=1000` → sucesso |
| Aviso do Claude Code de que `openrouter/free` não é modelo reconhecido internamente | Modelo de gateway descoberto via gateway, não conhecido nativamente pelo CLI | Aviso esperado; a execução prosseguiu e respondeu corretamente |

### 4. Wrapper `Start-ClaudeCode`

- `claude.exe` localizado com `Get-Command`: `C:\Users\lenovo\.local\bin\claude.exe`.
- Loader definido no perfil PowerShell
  (`D:\Usuario\Documentos\PowerShell\Microsoft.PowerShell_profile.ps1`),
  alias global `claude` → `Start-ClaudeCode`.
- Fluxo: descriptografa `key.sec` sob demanda → define variáveis **apenas durante
  a execução** → executa o binário → limpa tudo no bloco `finally`.
- Variáveis de ambiente utilizadas:
  - `OPENROUTER_API_KEY` = chave descriptografada
  - `ANTHROPIC_AUTH_TOKEN` = chave descriptografada
  - `ANTHROPIC_BASE_URL` = `https://openrouter.ai/api`
  - `ANTHROPIC_API_KEY` = vazia (evita conflito com outra credencial)
  - `CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY` = `1`
- Limpeza no `finally`: remove as cinco variáveis do processo, libera o BSTR
  (`ZeroFreeBSTR`) e força coleta de lixo. O segredo permanece fora do repositório.
