## 1. Etapa realizada

Implementação da compatibilidade determinística por extensão.

Princípio confirmado:

```
IA PROPÕE
→ CÓDIGO VALIDA
→ CÓDIGO EXECUTA
→ CÓDIGO VERIFICA
→ CÓDIGO REGISTRA
```

A decisão de tipo-base não deve depender da IA quando a extensão permite
determinação segura.

---

## 2. Implementação

### Em `nucleo.py` foram adicionados:

* `EXTENSAO_PARA_TIPO` — mapeamento extensão → tipo
* `TIPO_PARA_CATEGORIA_BASE` — mapeamento tipo → categoria-base do catálogo
* `_tipo_por_extensao()` — retorna o tipo para uma extensão
* `_categoria_base_compativel()` — valida se a categoria proposta é
  compatível com o tipo determinístico; se incompatível, força a
  categoria-base correspondente

### Mapeamentos implementados:

```
imagem       → Fotos
video        → Vídeos
audio        → Áudio
documento    → Documentos
planilha     → Documentos
apresentacao → Documentos
```

### Extensões atualmente cobertas:

```
Imagens:
.jpg .jpeg .png .gif .webp .heic .bmp .tiff

Vídeos:
.mp4 .mkv .avi .mov .wmv .webm .flv .m4v

Áudio:
.mp3 .wav .m4a .flac .aac .ogg .wma .opus

Documentos:
.pdf .doc .docx .txt .md .rtf .odt .epub

Planilhas:
.xls .xlsx .csv .ods

Apresentações:
.ppt .pptx .odp
```

### Regra:

```
extensão conhecida
→ categoria-base determinística
→ IA não decide o tipo-base
```

A IA continua podendo decidir uma subcategoria semântica quando ela
realmente existe.

Exemplos:

```
foto.jpg
→ Fotos/
→ IA pode decidir Fotos/Família ou Fotos/Viagens

video.mp4
→ Vídeos/
→ IA pode decidir Vídeos/Família ou Vídeos/Cursos

audio.mp3
→ Áudio/
→ atualmente categoria-base sem subcategorias

documento.pdf
→ Documentos/
→ IA pode decidir Documentos/Pessoal, Financeiro etc.
```

Extensão desconhecida:

```
.xyz
→ nenhuma regra determinística
→ mantém a proposta da IA
```

### Integração em `_validar_proposta`:

A função recebe agora o parâmetro `extensao`. Após validar a categoria
contra o catálogo, chama `_categoria_base_compativel()`. Se houver
incompatibilidade entre o tipo da extensão e a categoria proposta, a
categoria é corrigida para a categoria-base correspondente.

A chamada em `Agente.processar` passa `percepcao["extensao"]` para
`_validar_proposta`.
