## Conhecimentos consolidados

O Git possui três áreas importantes para nosso fluxo:

Working Directory → Staging Area → Repository

Aprendemos que:

- git status mostra o estado atual.
- git diff mostra alterações fora do staging.
- git add coloca alterações no staging.
- git diff --staged permite revisar o próximo commit.
- git commit cria um ponto permanente no histórico.
- git restore pode descartar alterações ainda não confirmadas.
- git add -u pode preparar alterações e exclusões de arquivos já rastreados.
- git log --oneline permite acompanhar a evolução do laboratório.
- Arquivos Untracked não fazem parte do histórico até serem adicionados.
- Arquivos removidos que já eram rastreados aparecem como deleted.
