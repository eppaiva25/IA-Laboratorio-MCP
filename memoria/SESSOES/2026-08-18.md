## Conhecimentos consolidados

O Git possui três áreas importantes para nosso fluxo:

Working Directory → Staging Area → Repository

Aprendemos que:

- git status mostra o estado atual.
- git diff mostra alterações fora do staging.
- git add coloca alterações no staging.
- git diff --staged permite revisar o próximo commit.
- git commit cria um ponto permanente no histórico.
- git restore pode descartar alterações ainda não confirmadas.
- git add -u pode preparar alterações e exclusões de arquivos já rastreados.
- git log --oneline permite acompanhar a evolução do laboratório.
- Arquivos Untracked não fazem parte do histórico até serem adicionados.
- Arquivos removidos que já eram rastreados aparecem como deleted.

- Usamos `git diff` para revisar a alteração ainda no Working Directory antes de qualquer decisão.
- Usamos `git add README.md` para mover a alteração para a Staging Area.
- Usamos `git diff --staged` para revisar novamente a alteração já preparada.

### Conhecimentos consolidados nesta etapa

- O Claude Code opera sobre o Working Directory real do repositório — as edições que ele faz são edições reais no sistema de arquivos.
- O fluxo "alteração → git diff → git add → git diff --staged → git commit → git status" permanece válido quando a alteração é feita por um agente.
- `git diff` (sem flags) mostra o que ainda está fora do staging; `git diff --staged` mostra o que já foi preparado.
- Após um commit bem-sucedido, `git status` deve voltar a indicar Working Directory limpo — essa é a confirmação de que não há alteração pendente fora do histórico.
- O Git funciona como camada de segurança para qualquer alteração, inclusive as feitas por agentes de IA: cada commit é um ponto de retorno.

### Princípio reforçado

O Git deve funcionar como **camada de segurança e revisão** para alterações realizadas por agentes de IA, exatamente como funciona para alterações humanas.

Decidir **aceitar** ou **rejeitar** uma alteração feita pelo agente é uma decisão humana, usando os mesmos comandos Git já aprendidos (`git add`, `git restore`, `git commit`).
